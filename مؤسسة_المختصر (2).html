⚠️ تنبيه: هذا الإعداد لمرة واحدة فقط. بعدها بياناتك تنحفظ تلقائياً.
1 اذهب إلى Google Cloud Console

افتح هذا الرابط في متصفحك:

https://console.cloud.google.com/

سجل دخول بحساب Google الذي تريد استخدامه.

2 إنشاء مشروع جديد
  • اضغط على القائمة المنسدلة فوق (اسم المشروع)
  • اضغط "NEW PROJECT" / "مشروع جديد"
  • سمّه مثلاً: car-dealer
  • اضغط "CREATE"
3 تفعيل Google Drive API
  • في شريط البحث فوق، اكتب: Google Drive API
  • اضغط على النتيجة
  • اضغط زر "ENABLE" / "تفعيل"
4 إنشاء OAuth Client ID
  • من القائمة الجانبية: APIs & Services → Credentials
  • اضغط "+ CREATE CREDENTIALS" → OAuth client ID
  • لو طلب منك "Configure consent screen": اختر "External" واملأ الاسم والإيميل فقط
  • Application type: Web application
  • Authorized JavaScript origins: أضف رابط موقعك (مثل: https://yourname.github.io)
  • اضغط CREATE
  • راح يطلع لك Client ID - انسخه
5 الصق الـ Client ID هنا

ارجع للمنصة، الصق الـ Client ID في الخانة، واضغط "ربط Google Drive".

💡 تحتاج مساعدة؟ فيه فيديوهات شرح على YouTube ابحث عن:
"How to get Google Drive API Client ID"
